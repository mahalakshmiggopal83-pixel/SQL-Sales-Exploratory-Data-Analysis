SQL Sales Exploratory Data Analysis

Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on sales data using Microsoft SQL Server.

The objective is to explore sales transactions, customer information, and product details to understand business performance, identify sales trends, analyse customer behaviour, and evaluate product performance.

Using SQL queries, the project explores raw business data and transforms it into meaningful information that can support data-driven business decisions.

Project Objectives

* Explore and understand the structure of the sales database.
* Analyse customer and product information.
* Identify overall sales performance and key business metrics.
* Examine sales trends across different time periods.
* Identify top-performing and low-performing products.
* Analyse customer purchasing patterns.
* Generate meaningful insights from sales transactions.

Tools and Technologies

* **Microsoft SQL Server** – Database management and querying.
* **SQL Server Management Studio (SSMS)** – Writing and executing SQL queries.
* **SQL** – Data exploration, aggregation, analysis, and reporting.
* **GitHub** – Project documentation and portfolio management.

Database Overview

The project uses a sales data warehouse containing three main tables:

1. gold.fact_sales

Contains sales transaction information.

Key columns include:

* Order Number
* Product Key
* Customer Key
* Order Date
* Shipping Date
* Sales Amount
* Quantity
* Price

2. gold.dim_customers

Contains customer-related information.

Key columns include:

* Customer Key
* Customer ID
* Customer Number
* First Name
* Last Name
* Country
* Gender
* Marital Status
* Birth Date
* Create Date

3. gold.dim_products

Contains product-related information.

Key columns include:

* Product Key
* Product ID
* Product Number
* Category ID
* Category
* Subcategory
* Maintenance Cost
* Product Length
* Start Date

SQL Analysis Performed

The project covers the following analytical areas:

1. Database Exploration

* Explored database objects and tables.
* Examined table structures and columns.
* Identified the available datasets.

2. Dimension Exploration

* Analysed customer information.
* Explored customer countries and demographics.
* Examined product categories and subcategories.

3. Date Exploration

* Identified the first and last order dates.
* Examined the overall sales period.
* Analysed customer age-related information.

4. Measure Exploration

Calculated important business metrics, including:

* Total Sales
* Total Orders
* Total Customers
* Total Products
* Total Quantity Sold
* Average Selling Price

5. Magnitude Analysis

* Analysed customers by country and gender.
* Examined product distribution across categories.
* Compared revenue across product categories.
* Analysed revenue generated by customers.

6. Ranking Analysis

* Identified the top five products by revenue.
* Examined the lowest-performing products.
* Identified the top ten customers by revenue.
* Analysed customers with the highest number of orders.

7. Change-over-Time Analysis

* Analysed yearly sales performance.
* Examined monthly sales trends.
* Calculated running totals of sales.

8. Additional Analysis

* Identified products that had never been sold.
* Examined orders containing multiple products.
* Classified sales transactions using CASE statements.
* Compared product prices with actual sales amounts.
* Identified products with the highest quantity sold.
